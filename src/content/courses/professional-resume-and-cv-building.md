## Course Overview

Create powerful, ATS-friendly resumes and CVs that get noticed by employers and pass automated screening systems.

## Learning Outcomes

By the end of this course, you will be able to:

1. Understand the difference between resumes and CVs
2. Optimize resumes for ATS (Applicant Tracking System)
3. Use AI to highlight achievements and quantify impact
4. Create multiple resume versions for different job roles
5. Apply design principles for visual hierarchy
6. Write powerful action verbs and achievement statements

## Topics Covered

* Understanding the difference between resumes and CVs (1 hour)  
* ATS (Applicant Tracking System) optimization: keywords, formatting, and structure (2 hours)  
* Using AI (ChatGPT/Claude) to highlight achievements and quantify impact (2 hours)  
* Creating multiple resume versions for different job roles (1 hour)  
* Design principles: choosing the right template and visual hierarchy (1 hour)  
* Writing powerful action verbs and achievement statements (1 hour)
