## Course Overview

Learn essential cybersecurity concepts and practices, from threat identification to security testing, opening pathways to careers in this high-growth, remote-friendly field.

## Learning Outcomes

By the end of this course, you will be able to:

1. Understand security principles and threat landscape
2. Apply network security basics
3. Grasp ethical hacking concepts
4. Perform security testing and vulnerability assessment
5. Navigate security compliance standards
6. Execute incident response procedures
7. Explore cybersecurity career pathways

## Topics Covered

* Security principles and the current threat landscape (2 hours)  
* Network security basics: firewalls, encryption, VPNs (3 hours)  
* Ethical hacking concepts and methodology (3 hours)  
* Security testing and vulnerability assessment techniques (4 hours)  
* Security compliance standards: ISO 27001 basics (2 hours)  
* Incident response procedures and security protocols (2 hours)  
* Career pathways in cybersecurity for women (2 hours)
