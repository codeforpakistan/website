## Course Overview

Learn to create a social media strategy, plan content, design graphics, and schedule posts.

## Learning Outcomes

By the end of this course, you will be able to:

1. Identify target audiences and choose appropriate platforms
2. Develop content strategies and content pillars
3. Use AI to create monthly content calendars
4. Design graphics for social media using Canva
5. Use social media scheduling tools

## Topics Covered

* Identifying a target audience and choosing the right platforms (2 hours)  
* Developing a content strategy and content pillars (2 hours)  
* Using AI to create a monthly content calendar (2 hours)  
* Designing graphics for social media using Canva (2 hours)  
* Introduction to social media scheduling tools (2 hours)
