## Course Overview

Learn to use Excel or Google Sheets for data organization, analysis, and business reporting.

## Learning Outcomes

By the end of this course, you will be able to:

1. Use basic formulas and functions (SUM, AVERAGE, IF)
2. Organize and format data effectively
3. Create charts and visualizations
4. Analyze data using PivotTables
5. Track budgets and financial data

## Topics Covered

* Basic formulas and functions (SUM, AVERAGE, IF) (3 hours)  
* Data organization and formatting best practices (2 hours)  
* Creating charts and visualizations (2 hours)  
* PivotTables for data analysis (3 hours)  
* Budget planning and financial tracking (2 hours)
