## Course Overview

Design and launch a beautiful, responsive website without writing any code using tools like Carrd or Webflow.

## Learning Outcomes

By the end of this course, you will be able to:

1. Navigate no-code platforms effectively
2. Design for responsiveness across devices
3. Build multi-page sites with forms and navigation
4. Style elements and publish websites
5. Manage domains and hosting

## Topics Covered

* Introduction to no-code platforms (Webflow/Framer) (2 hours)  
* Designing for responsiveness (desktop, tablet, mobile) (3 hours)  
* Building a multi-page site with a homepage, about page, and contact form (7 hours)  
* Styling elements and publishing your website (3 hours)
