**Total Duration:** ~8 Hours (Core Literacy) / 1-Month Bootcamp  
**Level:** Absolute Beginner

## Course Learning Outcomes

By the end of this course, learners will be able to:

1. Identify and operate basic computer hardware (Desktop, Laptop, Tablet).  
2. Navigate Windows operating systems and manage system settings confidently.  
3. Create a structured digital filing system to organize, copy, and delete data.  
4. Use web browsers and search engines to access information effectively.  
5. Set up and troubleshoot audio/video equipment for professional online meetings.  
6. Resolve common technical issues through basic troubleshooting techniques.  
7. Utilize keyboard shortcuts and productivity tips to work faster.  
8. Navigate local government portals and fintech apps for financial independence.

## Topics Covered

### MODULE 1: Hardware & Operating System Navigation

* **Computer Hardware Basics:** Understanding your device: Desktop, Laptop, and Tablet; Identifying ports (USB, HDMI, Power) and peripherals; Proper startup and shutdown procedures
* **OS Navigation & Settings:** Windows basics: Desktop, Taskbar, and Start Menu; Adjusting system settings: Wi-Fi, Sound, and Display; Personalizing the workspace for efficiency
* **Productivity Tips:** Essential keyboard shortcuts (Ctrl+C, Ctrl+V, Alt+Tab); Basic typing ergonomics and speed tips
* **Practical Activity:** The Setup Challenge: Identify all hardware components, connect to Wi-Fi, and customize the desktop taskbar.

### MODULE 2: Internet, Communication & AV Setup

* **Browsers & Search Engines:** Navigating the web: Chrome, Edge, and Safari; Effective Google searching: Keywords vs. Sentences; Managing tabs and bookmarks
* **Audio/Video Equipment:** Setting up and testing webcams and microphones; Using headphones for noise-free online meetings; Troubleshooting "No Sound" or "No Video" issues in Zoom/Meet
* **Professional Email & Cloud:** Setting up a professional Gmail/Outlook account; Introduction to Cloud storage (Google Drive/OneDrive), Access to information on Mobile phone
* **Practical Activity:** The Virtual Meeting Test: Join a mock online meeting, test AV gear, and share a cloud-hosted file link in the chat.

### MODULE 3: File Management & Troubleshooting

* **Managing Files & Folders:** Creating, renaming, and organizing folders; Mastering Copy, Paste, Move, and Delete actions; Understanding file extensions (PDF, DOCX, JPG)
* **Basic Troubleshooting:** The "Restart" rule and why it works; Managing system updates and "not responding" apps; Dealing with common internet connectivity issues
* **Digital Safety:** Recognizing phishing emails and scam pop-ups; Basic password hygiene and safety online
* **Practical Activity:** The Data Cleanup: Organize 10 random files into a structured folder system and perform a mock system update check.

### MODULE 4: Fintech, Government Portals & Freelancing

* **Local Government Portals:** Navigating Pakistan Citizen Portal, NADRA, and FBR Iris; Accessing digital certificates and verification services
* **Fintech & Money Apps:** Setting up and using SadaPay, NayaPay, EasyPaisa, or JazzCash; Depositing and withdrawing funds (including Qatar-to-Pakistan logistics)
* **Freelance Foundations:** Creative tools: Canva for design and CapCut for video; Introduction to online earning platforms (Fiverr/Upwork)
* **Practical Activity:** The Financial Roadmap: Set up a digital wallet and create a professional CV using a Canva template.
