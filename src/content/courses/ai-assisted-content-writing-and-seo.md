## Course Overview

Create compelling written content with the help of AI and learn SEO basics to make it discoverable.

## Learning Outcomes

By the end of this course, you will be able to:

1. Understand and apply SEO fundamentals
2. Use ChatGPT to brainstorm ideas and create outlines
3. Write and edit AI-generated drafts for various formats
4. Craft engaging social media captions and newsletters
5. Use tools like Grammarly for tone and clarity

## Topics Covered

* Fundamentals of Search Engine Optimization (SEO) (2 hours)  
* Using ChatGPT to brainstorm ideas and create outlines (2 hours)  
* Writing and editing AI-generated drafts for articles and web copy (3 hours)  
* Crafting engaging social media captions and email newsletters (2 hours)  
* Using tools like Grammarly for tone and clarity (1 hour)
