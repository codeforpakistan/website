The [Lahore Civic Hackathon](http://lhrhacks.devpost.com/), Jan 24-26, 2014, was a success! In case you missed it, never fear: it was covered by our own bloggers, social media partners, journalists, as well as several other blogs and news sites. For your convenience, we have consolidated all of them here so that you can review the exciting event that we witnessed.

Here were the Judges' favorite projects. Click the project name to learn more about the entry:

**Audience Favorite**: [Savaree](http://lhrhacks.devpost.com/submissions/20437-savaree))
**1st Place**: [PakSaaf](http://lhrhacks.devpost.com/submissions/20372-paksaaf))
**2nd Place**: [Blood for Life](http://lhrhacks.devpost.com/submissions/20434-blood-for-life-blood-donor-directory-stakeholder-exchange))
**3rd Place**: [WhichBus](http://lhrhacks.devpost.com/submissions/20375-whichbus))
**Best Open Source Redeployment**: [CiviSpot](http://lhrhacks.devpost.com/submissions/20380-civispot))

You can see all the open source projects in the [submission gallery](https://lhrhacks.devpost.com/project-gallery). We are looking forward to many of these apps going with the Lahore Brigade!
